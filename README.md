# Flock

Flock is a notetaking app meant to address certain issues with other available notetaking apps:

## Nested Structure:
The name flock is derived from the idea of nesting. I wasn't happy with the tool available to write notes in the way I wanted: a nested structure that allows for a clear, hierarchical structure, with the ability to write notes in a nested structure in the way I would write code in a nested structure. Features include collapsing nested structures. 

## Referencing:
Often times, when taking notes for an entire class, it can be easy to forget terms or definitions used or defined previously. I wanted a way to easily and automatically reference those.

## Quick, Easy Styling:
I wanted a flexible system to create quick to apply styles that allow me to mimick the way I take notes by hand/on an iPad.
